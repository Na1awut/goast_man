# ลุงหนุ่ม Square — บันทึกนำเข้าร้าน

- Store ID: `loongnoom-square`; โซน `cb1`; ที่ตั้ง **อาคาร CB1** ตามที่ผู้ใช้ยืนยัน
- 87 รายการ / 10 หมวด ราคา 7–50 บาท จากป้ายใน `src/picture/ร้านลุงหนุ่ม/-1536x307.jpg`
- กาแฟ 6 ชนิดแยกเย็น/ปั่น รวม 12 รายการ ผู้ใช้ยืนยันความหมายของราคาคู่แล้ว
- ทาโกยากิแยก 1 ลูก 7 บาท / 3 ลูก 20 บาท ไม่ใช้ตัวเลือก “พิเศษ” แทนจำนวน
- เมนูในกรอบเล็กซ้ายคำว่า Takoyaki อ่านชื่อไม่ชัด (20 / เพิ่มชีส 30 บาท) เก็บใน `pending` ของ JSON รอยืนยัน ยังไม่นำเข้า
- ราคาอ้างอิงป้ายที่ได้รับ ไม่ได้ยืนยันราคาปัจจุบันกับร้าน

## รูปและสถานะเริ่มต้น

รูปต้นฉบับทั้ง 4 อัปโหลดไป Supabase bucket สาธารณะ `store-banners/loongnoom-square/`:
`logo.jpg` โลโก้, `waffles.jpg` แบนเนอร์, `drink.jpg` รูปร้าน, `menu.jpg` ป้ายเมนู
รูปเมนูทั้ง 87 รายการใช้ภาพที่แยกจากป้ายต้นฉบับ 52 ภาพใน `loongnoom-photos/`
กาแฟ โกโก้นมเหนียว นมสด ผลไม้ โซดา ทาโกยากิ และวาฟเฟิลบางรสใช้ภาพร่วมกันตามหมวดบนป้าย
เป็นภาพจากป้ายความละเอียดต่ำ ไม่ใช่รูปถ่ายแยกทุกชนิด ดูพิกัดและรายการจับคู่ใน `loongnoom_photos.json`
ภาพ PNG 256 × 256 มีพื้นขาวเพื่อไม่ตัดส่วนของสินค้าเมื่อแสดงในช่องสี่เหลี่ยม
อัปโหลดไว้ที่ `store-banners/loongnoom-square/menu/`

ร้านเริ่ม **ซ่อน / ปิดรับออเดอร์** ตามค่าเริ่มต้นของหน้าทีมงานและร้านอื่นที่นำเข้า
ทีมเปิดได้ที่ **ร้านค้า → ลุงหนุ่ม Square → แสดงร้าน / เปิดร้าน** หลังตรวจข้อมูล
ไม่กำหนดเจ้าของร้าน ไม่ตั้ง Partner รีวิว หรือโปรโมชั่นขึ้นเอง
จุดวางเส้นทาง CB1 ใช้กลางอาคาร N20 จากผังแม่บท มจธ. และติด `approximate`
ยังไม่ใช่พิกัดสำรวจหน้าร้าน

## ทำซ้ำหรือแก้ข้อมูล

1. แก้ข้อมูลที่ตรวจแล้วใน `loongnoom_square.json`
2. รัน `node supabase/data/generate-loongnoom.mjs` จาก root repo
3. ทดสอบ `npm run test:sql` ใน `frontend`
4. Apply migration `20261012000000_cb1_zone.sql` และ commit ให้เสร็จก่อน
5. Apply `loongnoom_square.sql` ซึ่งมี transaction ของตัวเอง

สคริปต์ใช้ `on conflict (id) do nothing` จึงไม่สร้างรายการซ้ำหรือเขียนทับสิ่งที่ทีมแก้
หากต้องการแก้รายการที่นำเข้าแล้ว ให้แก้ผ่านหลังบ้าน หรือ migration เจาะจงรายการ
ไม่รัน seed รวมซ้ำบน production เพื่อเพิ่มร้านนี้
มี audit `STORE_IMPORTED` ระบุผู้ดำเนินการเป็น `SQL import (Supabase CLI)` และจำนวนแถวที่เพิ่ม

## แยกรูปและอัปเดตเมนูที่นำเข้าแล้ว

1. `node supabase/data/prepare-loongnoom-photos.mjs` สร้าง manifest และ SQL สำหรับเติมรูป
2. `powershell -NoProfile -ExecutionPolicy Bypass -File supabase/data/extract-loongnoom-photos.ps1` แยกพิกเซลจากป้ายเดิม
3. `node supabase/data/generate-loongnoom.mjs` ให้ import ใหม่มีรูปด้วย
4. อัปโหลด PNG ทั้ง 52 ไฟล์เข้าโฟลเดอร์ Storage ด้านบนก่อน
5. รัน `loongnoom_menu_photos.sql` เพื่อเติมรูปให้รายการเดิมที่ยังไม่มีรูปเท่านั้น

SQL เติมรูปไม่ทับภาพที่ทีมตั้งแล้ว ไม่เปลี่ยนราคา ชื่อ ความพร้อมขาย หรือสถานะร้าน และรันซ้ำได้
